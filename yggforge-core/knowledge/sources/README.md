## 1. 这一层是什么

`knowledge/sources/` 用来保存外部来源材料及其中间提炼结果。

它不是规则层，也不是最终模板层。

它的作用是：

- 保存原始输入
- 保存提炼中间产物
- 为后续晋升提供来源依据

## 2. 两个子目录怎么分

- [inbox/README.md](inbox/README.md)
  - 原始来源材料
- [distilled/README.md](distilled/README.md)
  - AI 或人工提炼后的中间结果

## 3. 推荐工作流

1. 先把来源材料放进 `inbox/`
2. 再提炼到 `distilled/`
3. 最后根据稳定性晋升到：
   - [../lessons/README.md](../lessons/README.md)
   - [../templates/README.md](../templates/README.md)
   - [../rules/README.md](../rules/README.md)
