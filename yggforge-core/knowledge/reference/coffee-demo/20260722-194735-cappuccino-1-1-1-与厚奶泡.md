# 卡布奇诺比例与奶泡

## 配比与奶泡

卡布奇诺传统比例 1:1:1：等量浓缩咖啡、热牛奶、厚奶泡。奶泡比拿铁更厚更干，至少 1cm。打奶泡时蒸汽棒尖端贴近液面多进气 5-8 秒，再下潜加热至约 65C。
