# 拿铁与卡布奇诺的奶泡区别

## 区别

拿铁与卡布奇诺的区别：拿铁以大量热牛奶为主，面上一层薄微泡；卡布奇诺奶泡厚而干，约占杯量三分之一。选奶泡厚度即可区分二者。
