# Decisions

如果你第一次进入 `knowledge/`，建议先看：

- [../README.md](../README.md)

这里保存设计决策与长期共识。

适合记录：

- 为什么选某个并发模型
- 为什么禁用某些语言特性
- 为什么选择某个 benchmark 方法
- 为什么某些模板被认定为标准做法

新增条目时建议从：

- [../templates/decision.template.md](../templates/decision.template.md)

front matter 必填 `type: decision`；`when_to_read` / `consequences_*` / `related` 写 YAML，正文保留 Context / Decision 叙述。
