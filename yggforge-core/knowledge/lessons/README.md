# Lessons

如果你第一次进入 `knowledge/`，建议先看：

- [../README.md](../README.md)

这里放错题本、踩坑、事故复盘与经验总结。

建议每个条目（`type: lesson`）至少覆盖：

- 正文 `## Observation`：发生了什么 / 根因
- 正文 `## Principle`：如何避免再次发生
- YAML：`applies_to` / `when_to_read`；若已晋升则填 `promoted_to`

推荐优先记录这几类经验：

- 用户对 Agent 的原则性纠正
- 反复出现的 review 问题
- 工具相关但尚未稳定到规则层的工作流经验
- 对外部参考仓库或方案的结构性反思

仓库级快速记录入口：

- `ygg remember <note>`

默认会把草稿写到：

- [inbox/README.md](inbox/README.md)

新增条目时建议从：

- [../templates/lesson.template.md](../templates/lesson.template.md)

> 客观描述性知识（事实/基线/定义/对比，无踩坑叙事）请放 [../reference/README.md](../reference/README.md)，不要放这里。
