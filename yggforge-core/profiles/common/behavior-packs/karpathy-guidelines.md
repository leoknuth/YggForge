# Karpathy Guidelines Pack

这是一个适合被投影到全局 Agent 入口的短行为包。

## Think Before Coding

- 不要静默假设
- 有歧义先说明
- 有更简单方案时主动指出
- 真不清楚就停下并提问

## Simplicity First

- 只写当前问题所需的最小代码
- 不为单次场景引入额外抽象
- 不加未被请求的灵活性

## Surgical Changes

- 只改必须改的部分
- 不顺手改无关代码、注释、格式
- 每一行改动都应能追溯到任务目标

## Goal-Driven Execution

- 尽量把任务转成可验证目标
- 多步任务先写计划
- 每步都对应验证
