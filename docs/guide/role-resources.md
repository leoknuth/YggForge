## 技能注册与选择顺序

role.yaml.skills 注册现役完整入口，不代表每任务读全部正文。准备接口读取完整 name、description 和 metadata，选定技能后全文加载其 SKILL。

显式任务 skills 或 CLI --skill 优先；未显式选择时先加载 default_skills，再完整加入 skill_workflows 中 --workflow 指定的技能组。只有未指定工作流时才按任务 tags 和描述额外自动匹配，可选项预算不截掉默认首入口或完整工作流。未知名称、工作流或无效引用报错。

默认路由承接原角色的专业工序。原根部 SKILL 若有效可按完整注册路径使用，技能 ID 与路径必须唯一对应；不能通过短入口替代长方法来规避载入。

## 正文完整性与窄读

五根件、context_files、角色 description、获选 SKILL、record_state 的 STATE 和已有 role_summary 正文不在加载层截断，也不会因超出旧 8K/12K/32KB阈值而丢失后半部分。支持专业方法保留原必要 reference 树，按其原触发与路由深读。 主入口已完整包含的source-skill/source-method包装副本应按逐项覆盖审计清除，同时修正resources声明和链接；原专业reference本身不因含source字样而被误删。

shared_hits 与 role_hits 仍按检索 budget 窄读，附 truncated 和来源指纹；预算用于限制本次相关命中，不是裁剪角色人格、质量关卡或整套工作流。summary 本身是有来源的派生摘要，全文载入与原 notes 全量注入不同。

## 静态资源声明

metadata.resources 可声明自身技能根内真实相对文件或目录：缺省安全扫描，[] 只给入口，非空列表限定投影文件树。声明缺失、越界、链接、凭据、生成缓存、依赖目录或压缩归档等禁项时拒绝，不扩大扫描或静默忽略后称完整。

模板、style、固定词库、脚本、字体、示例和许可证按原相对父树保留。安全路径校验不替代业务分类；真实客户、学情、用户 profile、运行反馈和行情数据不放静态资源清单。cache 工具脚本或现役 archive 命名方法按来源与用途识别，不以字面名称清退。

被选资源以原字节和层次投影，依赖与许可保持原契约。资源是否存在、是否能复制、是否能执行和是否服务连通分别判断。

## 五根件与补充设定

AGENTS、IDENTITY、SOUL、USER、TOOLS 承接完整角色设定，context_files 选取自身补充正文。目录章节使用当前 records/memories/skills；旧平台、路径与服务状态按必要适配说明落实。

USER 原文的事实来源、时效与适用主体明确标记，新任务的用户事实单独核对。完整保留原档案不意味着旧人物、持仓、客户、权限和学情自动属于当前任务。

## records和内部任务字段

records 用固定 ID 映射自身 `records/类别/实体/` 与 STATE，每项只保存 path、state。业务源稿、数据、代码、附件、字体和报告直接分类进入实体，事件与领域知识按角色 notes 类型保存。

task.project_id 保留知识作用域，也用于选择已注册的自身记录；匹配后恢复完整 record_state 与文件清单。task.project_root 保留显式外部项目根或解析后的自身记录根。未匹配 scope 不自动创建实体，不能访问另一角色目录或自身非记录私有区域。

role list --brief 输出 record_count。ContextBundle 使用 record_state；内部执行快照使用 record/，长期业务目录保持原生 records，不再维护整包来源项目。

## 快照与实际资料

task.files 明确选择记录或外部项目根内的相对文件，保留 record/data、record/scripts 等原层次；其它记录不会因同名或共同管理者被带入。

文本给完整所选正文，支持的二进制给快照路径、hash和bytes，实际处理需相应依赖。资产准备后变动须重加载；输入缺失、过大或未支持会明确拒绝，按获准任务窗口或格式处理，不静默截断。技能支持资源和外部任务输入具有不同的体积与类型检查。

record_state 自身标记 `record-state-is-context-not-confirmed-fact`。STATE、原报告、源文件或准备成功只能证明资料与状态恢复，不证明数据新鲜、研究复算、成绩提交、音乐生成或发布完成。

## 工具能力和异常入口

本机 tools 配置记录客户端、角色准入、安装、版本、认证和状态；上下文只公开非敏感目录状态。元数据检查与业务请求分开，既有授权持续适用；未接通部分保留具体缺口与接口契约。

客户端版本、离线 capabilities、源目录及 metadata.availability 都不能代替真实查询与业务验证。原自动 Mock 降级应持续显式标为模拟，不能充当真实行情、财务或实验结果。

缺损 SKILL 单列源缺陷：可靠同实现完整版本可按证据修复；不能修复时不注册为恢复能力，保留原支持资源与异常处置。完整专业方法不会因为当前服务未安装而被删除；已明确退役的废版本按用户清退授权处理。
