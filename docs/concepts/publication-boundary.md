# 发布与隐私边界

同一知识真源可以用于私有维护与对外发布。发布时先检查标签和文件边界，再检查发布授权，不要求条目额外贴“共享”标签。无隐私标签只表示具备共享资格，不代表已经授权发布。

## 默认规则

- 条目没有精确的 `隐私` 标签时，默认成为共享候选；其它记忆仍须逐项批准。
- 框架路径可由调用方明确声明为自动发布范围；记忆批准只认精确条目 ID 或相对文件路径，不把目录批准当成逐项批准。
- 带 `隐私` 标签的条目不可共享；过滤库同时保守拒绝 `隐私-` 开头的子标签。即使批准了该条目或把它放进框架范围，也不能覆盖隐私拒绝。
- 不需要新增“共享”标签，也不用第二个可见性字段替代 `tags`。
- 框架文件使用同一检查，不能因为属于脚本、配置或说明文档就获得豁免。

Markdown 的标签放在开头 YAML front matter，可使用中文、带引号的 inline list 或 block sequence。UTF-8 BOM 不影响判断。正文讨论隐私不等于给条目贴了隐私标签。

## 附件与混合文件

被私密条目引用的本地图片、媒体、文档、数据集和显式附件继承隐私，不可单独发布。已批准记忆或合格框架的附件可随其发布；若同一附件也被私密条目引用，隐私拒绝优先。显式附件目录的子文件也继承。继承按资源的真实路径计算，不能通过更换链接名绕过。

普通 Markdown 条目之间的知识链接不自动传播隐私：私密经验引用一条公共规则，不会把该规则本身改成私密。图片引用、HTML 媒体引用、reference-style 附件和 JSON 的 `assets` / `attachments` / `files` 等显式附件字段会传播。

JSON 会递归检查全部 `tags`。只要混合数组或嵌套对象中的任一条目带隐私标签，整份文件都不可发布，不能只删除标签或对外复制其中一部分。需要公开的内容应先形成独立、可审核的文件。

## 路径与内容检查

- `.git`、运行时和生成物目录默认不从真源发布。
- 原始路径与 resolve 后路径都必须留在指定根内；目录链接不被递归跟随。
- 指向运行时的链接同样排除；资源别名不会改变继承结果。
- 显式私密标记和已知秘密格式会拒绝发布，原因只返回固定代码，不回显内容。
- 可通过通用 `forbidden_terms` 拒绝出现在相对路径或内容中的禁用字串；库不硬编码部署名称或用户信息，也不在理由中回显该字串。
- 标签或 JSON 无法安全解析时保守拒绝，不把解析失败当成“没有隐私标签”。

## 使用发布过滤库

实现位于 `yggforge-core/scripts/policies/publication.py`，仅使用标准库，不执行复制、Git 或网络操作。

```python
from pathlib import Path
from policies.publication import evaluate_file, select_files

root = Path("/absolute/source-root")
eligibility = evaluate_file(Path("knowledge/example.md"), root)
# ELIGIBLE 只表示通过隐私/路径检查，不是发布授权。

# 两阶段扫描包含附件继承；结果可用于生成选择清单。
for relative_path, decision in select_files(
    root,
    approved_items=("approved-entry-id",),
    framework_paths=(Path("scripts"),),
):
    if decision.allowed:
        pass  # 调用方按审核后的清单复制
```

单文件入口接受 `inherited_tags`；已有资产关联表的调用方可直接传入继承标签。`evaluate_file` 返回共享资格，`select_files` 才应用发布授权：未批准的非框架内容返回 `APPROVAL_REQUIRED`，其 `eligible=True`、`allowed=False`。重复条目 ID 不能批量授权，需按精确路径选择。默认遍历会剪掉运行时与生成物，也可给 `select_files` 传 Git 跟踪文件清单；即使只选择附件，仍检查根内未被选中的私密来源，防止继承漏检。只发布 `allowed=True` 的文件，清单中只记录相对路径与原因代码。

## 验收与限制

回归测试覆盖 Markdown / JSON 隐私、BOM、中文/inline 标签、无标签候选与逐项批准区别、混合 JSON、资源继承、链接越界、运行时别名、通用禁字串和框架无豁免。

发布库不承诺通用秘密识别，标签维护仍是发布方的责任。Markdown YAML 仅解析标签所需的小型子集；复杂别名或不支持的标签表达式会拒绝发布。结构化元数据读取上限为 16 MiB，超过上限需拆分或显式审查。

选择清单生成后到复制之间可能发生文件变更。调用方应固定版本，或在复制前复核文件内容与路径；不要把旧清单当作永久授权。
